Constraints

  • Legacy migration is a prerequisite. The target tooling (SDK-style csproj, PackageReference, .slnx, test project, Harmony 2.4.2) requires migrating off the current non-SDK .csproj + packages.config + .sln + Harmony 2.3.6 first.
  • NetAnalyzers pinned to 9.0.0. Do NOT bump to 10.0.300 — the .NET 10 analyzer band adds CA rules that fail the build under warnings-as-errors. The pin is deliberate (per user decision).
  • FluentAssertions pinned to 7.x (Apache-2.0). Never upgrade to 8.x — 8.x is commercially licensed (Xceed). License-driven hard constraint.
  • net48 target only. Dictated by RimWorld's Mono runtime; cannot target modern .NET runtimes.
  • RimWorld assemblies are not NuGet. Assembly-CSharp + Unity modules are HintPath references resolved from a local RimWorld install; build requires the game installed.
  • LordKuper.Common is upstream, read-only. Consume its public surface; do not fork (resolved from ..\..\rimworld-common\1.6\Assemblies).
  • Transpiler must fail soft. The single Harmony transpiler on JobGiver_OptimizeApparel.ApparelScoreRaw searches for an IL anchor (the Apparel.GetSpecialApparelScoreOffset call site); if the anchor is not found it logs an error and returns the original IL unchanged rather than throwing — vanilla scoring stays intact.
  • Compile-only references must not ship. Harmony and LordKuper.Common are Private=False / compile-only — runtime copies come from the player's installed mods.
  • Warnings-as-errors (target). Build clean under TreatWarningsAsErrors — any analyzer warning fails the build.
  • Published mod. Live on Steam Workshop (1984694952); changes affect existing subscribers and saved games (ExposeData / Scribe_* compatibility matters).

Per-tech risk vs LLM training cutoff (all versions verified latest-stable / pinned on 2026-06-07). Detailed notes per tech live in design/architecture/tech-reference/.

  • HIGH LordKuper.Common — private upstream, zero training coverage; consumed surface grep-confirmed only (Logger, RimWorldTime, ThingCache, WorkTypeThingRule, UI.Tabs/Fields/Widgets.WorkTypeThingRuleWidget).
  • MEDIUM RimWorld / Unity API (game-bound, 1.6) · NUnit 4.x (API differs from 3.x) · dotnet SDK 10.x toolchain · jb 2026.1.2 CLI/SARIF · NetAnalyzers pin (9.0.0 vs latest 10.0.300) · legacy→SDK csproj migration (project-format change).
  • LOW C# / net48 · Lib.Harmony 2.4.2 (single transpiler; legacy was 2.3.6) · Microsoft.NET.Test.Sdk 18.6.0 · NUnit3TestAdapter 6.2.0 · FluentAssertions 7.2.2 usage (HIGH only if upgraded past 7.x unaware).

Overall: HIGH (driven by the LordKuper.Common upstream dependency).
